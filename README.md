# 🍋 Little Lemon Android App

An Android restaurant menu application developed as part of the Meta Android Developer Professional Certificate program, in the Create User Interfaces in Android Studio course.

## Technologies
- Kotlin
- Jetpack Compose
- Material Design
- Themes and Styles

## Features
- Browse the restaurant menu.
- Explore food categories and item details.
- Navigate between app screens.

## Download
Download the latest APK from the [Releases](../../releases) section.

## Learning Objectives
Practice building Android user interfaces, reusable composable functions, consistent app theming, and screen navigation.
